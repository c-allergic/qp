把「我为什么会问这个问题」记成一棵树

读论文、查资料的时候，一个问题常常牵出下一个问题；等一路弄清楚， 最初想问什么已经记不清了。
qp 把这条追问过程记成一棵树：每个节点是你当时的问题原话， 根节点始终保留最初的那个问题。

先玩玩看 ↓ 在 GitHub 上看
装起来大概这样 ↓ 
# 取回代码，加一条全局命令
git clone https://github.com/c-allergic/qp.git ~/apps/qp
ln -sf ~/apps/qp/qp.py /opt/homebrew/bin/qp   # Intel Mac 用 /usr/local/bin

cd ~/Documents/我在读的论文
qp new "为什么 TCP 要三次握手？"
qp ui                                          # 打开图形界面

为什么做这个

普通笔记留下了结论，丢掉了过程

为了搞懂 A，你去查 B；为了 B，又得先弄清楚 C……等你终于明白 C，
已经想不起来自己为什么要出发。

笔记通常只保留结论，「当时卡在哪个说法、为什么会问到这里」这一层没有被记下来。 但在复习、或者同一个知识点再次卡住的时候，这一层往往更有用。

qp 的做法是：根节点保留最初的问题；每个子节点记录的不是「子议题」， 而是「父节点里哪个说法我没弄懂」；一条分支想通后可以收口，写下卡点和结论。

AI 梳理：把你想到过的问题列出来

读完整棵树之后，它列出你提到过哪些问题，以及每个问题后面跟着什么回答或更深的追问。 结果放在一个可编辑的框里，你可以修改之后再决定要不要保存。

安装

几步就能装好

环境需求

系统macOS
Python3.8 或更高
浏览器任意，推荐 Chrome
模型端点可选，仅「对话」和「AI 梳理」需要

安装

  1. 把仓库克隆到本地，让其中的脚本与页面放在同一个目录。
  2. 加一条软链，把它变成全局命令。
  3. 在要记录的目录里执行 qp init。
git clone https://github.com/c-allergic/qp.git ~/apps/qp
ln -sf ~/apps/qp/qp.py /opt/homebrew/bin/qp

cd ~/Documents/我在读的论文
qp init
qp ui

所有内容保存在运行 qp 的那个目录下的 .qp/ 里， 没有账号、没有云同步、也没有遥测。
